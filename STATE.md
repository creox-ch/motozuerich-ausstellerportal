## ✅ Момент выдачи доступа — решено 12.08

**В портале только те, кто уже согласован и оплатил.** Ссылка на вход уходит
после оплаты, а не сразу после согласования заявки — решение Иванны, отменяет
более раннее описание Ксении от 11.08.

```
план залов → заявка → согласование по телефону/почте
   → счёт за площадь ВНЕ портала → оплата
   → Messeleitung выдаёт доступ в админке → письмо-приглашение
   → кабинет
```

**Счета в портале при этом остаются.** Внутри кабинета экспонент заказывает
технику, рекламу, парковку — за эти заказы выставляются **дополнительные
счета**. То есть «Dokumente & Rechnungen» — не архив оплаченного, а рабочий
раздел: первый счёт (за площадь) приходит туда уже закрытым, следующие
выставляются внутри портала.

**Разблокировано:** письмо-приглашение (C3), раздел счетов (B5).

ничего не разрешал.
