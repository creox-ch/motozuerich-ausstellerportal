## ✅ Момент выдачи доступа — решено 2026-08-12

**В портал попадают только уже согласованные и оплатившие.** Решение Иванны;
оно отменяет более раннее описание Ксении от 11.08, где доступ давали сразу
после согласования заявки.

```
план залов → заявка → согласование → счёт за площадь ВНЕ портала → оплата
   → Messeleitung выдаёт доступ → письмо-приглашение → кабинет
```

**Счета в портале остаются.** За дополнительные заказы (техника, реклама,
парковка) экспоненту выставляются **дополнительные счета** уже внутри кабинета.
Раздел «Dokumente & Rechnungen» — рабочий, а не архивный: первый счёт приходит
туда закрытым, следующие выставляются внутри.

**Разблокировано:** C3 (письмо-приглашение), B5 (счета).

**Осталось выяснить по этой линии:** как именно рождается дополнительный счёт —
Messeleitung кладёт PDF руками или портал считает сумму по заказам. Пока цен
нет (A6), вопрос не срочный: до заполнения `mz_service_katalog` считать нечего.
